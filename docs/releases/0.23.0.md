# ReviewKit 0.23.0

This release includes the following changes:

- Adds public source and review-tree APIs for document and text inputs,
  document-source context bounds, reconciliation requests, and DOCX change
  provenance.
- Carries complete document-source context to the document review level and
  keeps fragment-level evidence local, so document-wide absence claims require
  complete source coverage.
- Separates model-facing review payloads from host-owned audit enrichment and
  preserves finding/action lineage for downstream audit consumers.
- Splits action preparation, targeting, overlap handling, and comment
  formatting into focused generic modules while retaining deterministic,
  fail-closed application behavior.
- Removes the obsolete `reviewkit.docx_package` compatibility shim and the
  broken `reviewkit-effector` console surface.

The release uses the stable Docxtor `v0.14.3` tag and keeps the required Takt
`v0.3.2` dependency.
