# ReviewKit 0.24.1

Breaking cleanup. Pack + `DecisionClient` + `LLMClient` is the only review
path. The fused `pack=None` single-pass is gone.

0.24 is a refined generic review process, not a legal domain in core. The
same engine reviews a privacy notice or a newspaper article; only Pack
content changes. Pack schema stays abstract: functions, rules, units.

- Hosts import typed objects (`Pack`, `DecisionClient`, `LLMClient`, `Rule`,
  `SourceUnit`, `FragmentDecisionState`, `DocumentDecisionState`) and pass
  instances. JSON files load through `Pack.model_validate` /
  `Pack.model_validate_json` only.
- `review_tree`, `review_source`, `review_document`, and `TaktReviewer`
  require `pack` and `decision`. There is no fused `complete_json` of
  findings+actions.
- Decision payloads are frozen Pydantic models holding a typed `SourceUnit`,
  not dict dumps.
- CLI requires `--pack`, `--decision`, and `--llm`.
- Gaps remain `ontology.function_ids() − covered()` on the host.
  `detect()` is internal.

Host guide: README and [`docs/host-integration.md`](../host-integration.md).
