# ReviewKit 0.24.0

Breaking change. A review given a `Pack` runs three passes instead of one.

- `review()` and `review_document()` take `pack: Pack | None = None`. `None`
  keeps the single fused pass. The profile stays the reviewer's behavior; the
  pack is the game.
- Pass 1 names a fragment with function ids from the ontology. It does not
  judge or edit, and it receives neither rules nor source text.
- Pass 2 returns a `Verdict`: `keep`, `change`, `delete`, `insert`, or
  `missing`. A `defect` rule judges one named fragment. A `close` rule judges
  the whole document, and it is the only place a function can be missing. The
  model receives the one source unit that rule cites.
- Pass 3 writes `replacement_text` for `change`, `delete`, and `insert`. Below
  the profile's confidence floor the action goes to a person and the model is
  not called.
- The host records a `PassTrace` for the checks it can make without a model:
  function ids belong to the ontology, a fragment carries no close rule, and
  absence is computed from `ReviewState.covered()`.
