# ReviewKit 0.24.0

Breaking change. A review given a `Pack` runs two scans plus an optional write.

- `review_tree` / `review_document` take `pack: Pack | None = None`. `None` is
  explicit legacy compat for the single fused pass. The intended path always
  receives a pack (the game). The profile stays the reviewer's behavior.
- A pack is ontology + rules + units. It is not `instructions.md`,
  `external_review_context`, or `profile.toml`. `SourceUnit.force` is data
  (`binding`, `dead`, …). `Rule.when` is `always`, `function_present`, or
  `function_absent`.
- Pass 1 names every sentence, paragraph, section, and document through
  `DecisionClient.decide` (separate noul questions per function). Tags are not
  findings, not actions, and not `RawSignal`.
- Pass 2 judges matching `when` rules and the one cited `SourceUnit`. Close /
  `function_absent` runs only on the document, and only for functions
  `covered()` does not list. Gaps are `ontology.function_ids − covered()`.
- Pass 3 writes `replacement_text` through `LLMClient.complete_json` only for
  `change` / `delete` / `insert` above the confidence floor. Otherwise a person.
- ReviewKit is a generic process. The host injects `DecisionClient` and
  `LLMClient` at the call site. Core does not ship a model runtime, client,
  URL, or weight name.
