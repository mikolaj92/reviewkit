# ReviewKit 0.24.0

Breaking change. A review given a `Pack` runs two scans plus an optional write.
The host injects model plugins; ReviewKit does not ship a model runtime.

- **Pack** is ontology + rules + units. It is not `instructions.md`,
  `external_review_context`, or `profile.toml`. `SourceUnit.force` is data.
  Unified `Rule` uses `kind` / `scope` / `when`.
- **Name** every sentence, paragraph, section, and document through
  `DecisionClient.decide`. Tags only — no findings, no actions, not
  `RawSignal`.
- **Judge** matching `when` rules and the one cited `SourceUnit`. Close /
  `function_absent` is document-only. Gaps are
  `ontology.function_ids − covered()` on the host.
- **Act** through `LLMClient.complete_json` only for `change` / `delete` /
  `insert` above the confidence floor.
- Call site injects `decision=` and `llm=`. `pack=None` is explicit legacy
  compat for the single fused pass. A pack review requires `DecisionClient`.
- Core does not ship a model runtime, client, URL, or weight name.
